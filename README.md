# ⚡ E-Cell CSE Website

An interactive, responsive, and dark-themed landing page designed for the **Entrepreneurship Cell (E-Cell) - Computer Science and Engineering Department**, KIT's College of Engineering, Kolhapur.

---

## 🚀 Features

* **Modern Dark-Gold Aesthetic:** Custom CSS design built with dark backgrounds, gold gradients, glassmorphism headers, and glowing badge animations.
* **Responsive Layout:** Optimized for desktop, tablet, and mobile views.
* **Interactive Elements:**
  * Floating glassmorphism navbar.
  * Right-aligned fixed social navigation bar.
  * Animated marquee ticker highlighting key initiatives.
  * Dynamic pulse animation for the hero badge emblem.
* **Structured Sections:** Includes Hero, About Us / What We Do cards, CTA Banner, and Footer.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structural layout.
* **CSS3:** Custom properties (variables), Flexbox, CSS Grid, Keyframe animations, and Media queries.
* **Inline SVG:** Lightweight scalable vector icons for social links and features.
